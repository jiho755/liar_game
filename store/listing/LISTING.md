## 7. Play Console 진행 체크리스트 (순서대로)

1. 개발자 계정 만들기 (개인, 등록비 US$25 1회, 본인 확인과 연락처 이메일·전화 인증, 스토어에 공개될 개발자 이메일 정하기)
2. privacy.html에 실제 이메일 주소를 넣고 GitHub Pages에 배포 후 URL 접속 확인
3. 앱 만들기: 이름 "성경 라이어", 기본 언어 한국어, 앱 유형 "게임", 무료, 정책·수출법 동의
4. 서명 키스토어 보관 (Play 앱 서명 사용, 업로드 키스토어와 비밀번호는 안전하게 백업. `store/KEYSTORE.md` 참고)
5. 앱 콘텐츠 선언 입력: 개인정보처리방침 → 앱 액세스 → 광고 → 콘텐츠 등급 → 타겟층 → 데이터 보안 → 기타(정부·금융·건강 등)
6. 기본 스토어 등록정보 입력: 이름, 간단한 설명, 자세한 설명, 아이콘, 대표 그래픽, 스크린샷 6장, 카테고리·태그, 연락처 이메일
7. AAB(Android App Bundle) 빌드 후 **비공개 테스트(Closed testing)** 트랙에 업로드, 테스터 목록(이메일 목록 또는 Google 그룹) 등록 (targetSdk가 Play의 현재 요구 수준을 만족하는지 확인)
8. 테스터 12명 이상 모집, 14일 연속 참여 유지 (아래 참고)
9. 14일 후 콘솔에서 "프로덕션 액세스 신청"에 답변 작성 (테스트 방법, 받은 피드백, 앱 준비 상태)
10. Google 검토 통과 후 프로덕션 트랙에 릴리스 (보통 검토에 며칠, 첫 출시는 더 걸릴 수 있음), 게시 상태 확인
11. 출시 후: 스토어 URL 확인, 광고를 추가할 때는 선언·방침·데이터 보안 양식을 먼저 갱신
